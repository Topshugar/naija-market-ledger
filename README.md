# Naija Market Ledger

Offline-first sales ledger for low-end phones like Redmi A2+. Built for Nigerian small shops with no internet.

### Why?
Market women in Suleja, Onitsha, Aba lose sales records when phone dies or data finishes. This app saves everything offline to SQLite - no data needed.

### Features
- Works 100% offline
- Saves to SQLite, no data loss
- Very light - works on 2GB RAM phones (Redmi A2+, Tecno Pop)
- Instant total calculation in Naira

### How to Fork & Run
1. Click **Fork** button top-right
2. Clone or download
3. `pip install -r requirements.txt`
4. `python App.py`
5. Open http://localhost:5000 on your phone

### For Devs
- `App.py` = backend logic
- `templates/index.html` = frontend
- `sales.db` = auto-created database (ignored in git)
