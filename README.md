# Naija Market Ledger

Offline-first sales ledger for low-end phones like Redmi A2+. Built for Nigerian small shops with no internet.

## Features
- Works 100% offline
- Saves to SQLite, no data loss
- Very light - works on 2GB RAM phones

## How to Fork & Run
1. Click Fork button top-right
2. `pip install flask`
3. `python App.py`
4. Open http://localhost:5000
